# Open Source Dataset Attributions & Licences

In compliance with open-source licensing requirements (including CC BY 4.0), MediTrack attributes all training and validation datasets utilized in development:

## 1. Pharmassist Dataset
- **Authors**: Kapilesh N, Tharaka P, Eesha C, Rekha D, Bhargavi R
- **Institution**: Vellore Institute of Technology, Chennai, India
- **Repository**: Mendeley Data
- **DOI**: `10.17632/zbnhmbbymd.1`
- **URL**: https://data.mendeley.com/datasets/zbnhmbbymd/1
- **Licence**: Creative Commons Attribution 4.0 International (CC BY 4.0)
- **Usage in MediTrack**: Used for strip domain realism, background variation, and semi-supervised silver pseudo-labeling.

## 2. Blister Pills Segmentation
- **Source**: Roboflow Universe
- **Workspace / Project**: `blisterdetection` / `blister-pills-segmentation`
- **Version**: 7
- **URL**: https://universe.roboflow.com/blisterdetection/blister-pills-segmentation
- **Usage in MediTrack**: Pretraining object detector on full vs empty blister cavity segmentation.

## 3. Team Own Photos
- **Provenance**: MediTrack development team real-world phone capture sessions (Stage 5 Data Collection Mode).
- **Rights**: Proprietary project gold test benchmark.
